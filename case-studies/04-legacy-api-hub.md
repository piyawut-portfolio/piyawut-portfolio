# เคส 4 — ฮับ API องค์กรที่วิ่งมานาน

**บริบท:** เข้าร่วม 2021 (แพลตฟอร์มมีมาก่อน) · ผู้ร่วมพัฒนาหลัก  
**สแต็ก:** Laravel 5.2, Oracle, MySQL, Swagger 2.0

## ปัญหา

ไคลเอนต์มือถือ/พอร์ทัลหลายรุ่นใช้พร้อมกัน  
อัปเกรดครั้งเดียวพังของเก่าไม่ได้

## สิ่งที่ทำ

- คง API หลายเวอร์ชันคู่ขนาน (พอร์ทัล B2B, การชำระเงินภาคสนาม)
- สะพาน Oracle / MySQL / Odoo, QR ธนาคาร, คลัง, มาร์เก็ตเพลส
- แนว strangler: ของใหม่อยู่ฮับรุ่นใหม่ ของเก่ายังเสิร์ฟของเดิม

## สิ่งที่สื่อสารให้ถูก

อย่าบอกว่า “สร้างฮับคนเดียวตั้งแต่ปี 2017”  
บอกว่าเป็นผู้ร่วมพัฒนาหลักตั้งแต่วันที่เข้าทำงาน และดูแลความเข้ากันได้ของโปรดักชัน
